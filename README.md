# Qubic Sentinel Bot 🤖

A Discord bot that automatically rewards community members for Qubic on-chain activity.

## 🚀 Features
- Listens for QUBIC token purchases via EasyConnect
- Automatically grants Discord roles
- Tracks user activity and rewards

## 🛠️ Setup
1. Clone the repo: `git clone https://github.com/YOUR_USERNAME/qubic-sentinel-bot.git`
2. Install dependencies: `npm install`
3. Configure `.env` file (see `.env.example`)
4. Run: `node index.js`
